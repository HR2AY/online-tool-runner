# 工具站自动化

一个用于发现、筛选并操作轻量在线工具站的 Codex Skill。

它适合处理文件转换、媒体处理、数据格式化等一次性网页工具任务。核心目标是优先寻找无需登录、无需付费、无需安装软件、无需多次跳转的工具站，完成真实任务后再把经过验证的操作方法沉淀到配方库中。

## 给人看

### 它能做什么

当你需要一个临时在线工具时，这个 Skill 会：

1. 先检查已经成功使用过的站点配方；
2. 没有合适配方时，通过搜索引擎寻找候选站点；
3. 排除需要登录、付费、安装软件、验证码或可疑跳转的站点；
4. 只检查网络和页面是否可用，不上传测试文件；
5. 使用你提供的真实输入执行任务；
6. 验证下载结果是否存在、格式是否正确、能否正常打开；
7. 成功后，把脱敏的操作流程保存到配方库。

典型任务包括：

- 压缩、转换或合并 PDF；
- 转换图片、音频和视频格式；
- 去除图片背景；
- 格式化或转换 JSON、CSV 等数据；
- 使用其他无需登录的轻量网页工具。

### 安全边界

- 网络预检不会创建、上传或提交测试文件和测试内容。
- 涉及个人、医疗、财务、合同、公司内部资料或其他敏感内容时，上传第三方网站前必须先取得用户确认。
- 不绕过登录、付费墙。
- 不接受浏览器扩展、捆绑软件、通知订阅或可疑下载。
- 不在配方库中保存用户文件、私人内容、Cookie、令牌或账户信息。

### 安装

将仓库克隆到 Codex 的 skills 目录：

```bash
git clone https://github.com/HR2AY/online-tool-runner.git ~/.codex/skills/online-tool-runner
```

也可以通过支持从 GitHub 安装 Skill 的工具，使用仓库地址：

```text
https://github.com/HR2AY/online-tool-runner
```

安装后可直接描述任务，或显式调用：

```text
使用 $online-tool-runner 找一个无需登录的在线工具，把这个文件转换成 PDF。
```

## 给 Agent 看

### 加载顺序

1. 先完整读取 `SKILL.md`，以其中的工作流程和安全边界为准。
2. 需要选择站点时，读取 `references/site-recipes.yaml`。
3. 配方只是候选方案；实际使用前仍要进行网络预检。
4. `agents/openai.yaml` 是界面元数据，不是任务执行规则。

### 必须遵守的执行原则

- 技术标识为 `online-tool-runner`，用户界面名称为“工具站自动化”。
- 先复用经过验证的配方，没有可用配方时再搜索。
- 搜索来源优先级为 Google、Bing、环境内置搜索、其他可信来源；某个来源被阻塞时立即切换。
- 最多初步查看五个候选站点，通常在三个认真评估过的候选失败后停止。
- 预检只测试页面连通性、加载速度、控件存在性和明显限制，不得提交任何样本输入。
- 页面应在约 10 秒内进入可操作状态；只有出现明确进度时才可延长至最多 30 秒。
- 操作优先级为官方稳定接口或命令行工具、DOM 或可访问性控件、屏幕操控。
- 只有真实用户任务成功、输出通过验证后，才能将站点登记为 `working`。
- 配方超过 90 天未验证时，应先按未经验证处理。

### 配方维护

`references/site-recipes.yaml` 是操作经验库，不是网站收藏夹。

新增或更新记录时，只保留复现流程需要的信息：

- 归一化任务意图；
- 站点名称和工具直达链接；
- 输入、输出格式及限制；
- 最简操作步骤；
- 完成信号和下载方式；
- 最后验证日期、状态、隐私说明和失败特征。

站点失效时标记为 `broken`；存在安全、隐私或误导性设计问题时标记为 `unsafe`。不要静默保留为可用状态，也不要记录用户的私人数据。
